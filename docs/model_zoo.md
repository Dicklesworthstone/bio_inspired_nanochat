## 2. One-Command Reproduction Recipe

To reproduce evaluation results or resume training from scratch:

```bash
# 1. Environment Setup (Python 3.14 + uv)
uv sync

# 2. Run Quality Gates & Unit Tests
uv run --no-sync python -m pytest tests/ -v

# 3. Evaluate Baseline vs Bio-All on Matrix A
uv run --no-sync python -m scripts.eval_matrix --preset bio_all --output runs/eval_repro.jsonl

# 4. Perform Paired Statistical Significance Test
uv run --no-sync python -m bio_inspired_nanochat.eval_stats runs/eval_repro.jsonl --baseline vanilla --alpha 0.05
```
